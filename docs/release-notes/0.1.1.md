# 鼠须管助手 0.1.1（预发布）

修了 40 多处小问题，加上自己的图标。非鼠须管 / Rime 官方出品。中文系统里显示「鼠须管助手」，其他语言显示 SquirrelHelper。

- 要求：macOS 27 或更新，Apple 芯片。
- 下载 `SquirrelHelper-0.1.1.zip`，解压后把应用拖进「应用程序」。已签名、已公证。
- 从 0.1.0 升级：退出旧版，用新版替换「应用程序」里的旧版。设置和备份都在，不受影响。

## 改了什么

- 新图标。
- 第一次打开：
  - 在应用里装好鼠须管后，不再误报「系统里没有鼠须管的输入源」，而是提示重新打开应用，点一下就自己重开、接着往下走；
  - 取消授权回到安装那一步；输错密码显示中文说明；
  - 设置好后如果还没切换到鼠须管，会提醒注销再登录一次（刚装好时 macOS 有时要这样才认得出它）。
- 接管已有配置：
  - 「改用起步方案」先确认；
  - 在方案列表后面追加（`schema_list/+`）的方案能认出来；
  - 认不出的写法会在预览里提醒。
- 备份和导入：
  - 还原最旧的那份备份后它不会被自动清理；
  - 已经由应用管理时，导入不再每次多一份永久备份；
  - 太大的 zip 不解压。
- 主窗口：
  - 选项改回原来的值后，不再显示「有改动还没应用」；
  - 读不了文本替换时，会建议先关掉同步；
  - 文本替换里只差大小写的同一条只算一次。
- 出错提示：没通知到鼠须管、请求太频繁、文件不是 UTF-8 等情况，都说清楚原因和怎么办。

全部条目见仓库里的 `docs/backlog.md`。

校验：`shasum -a 256 SquirrelHelper-0.1.1.zip`，结果应该是 `9849d76b0628a0eacb6330d0fd3a0d063975d6cb45cf5c3373626a702240f49e`（和附件里的 `.sha256` 一样）。

已知限制：
- 只支持 Apple 芯片；
- 界面只有中文；
- 应用不在后台常驻，文本替换的变化在打开应用时检查；
- 诊断页的部分提示还是命令行工具 rimectl 的说法（发布包里没有 rimectl）。
