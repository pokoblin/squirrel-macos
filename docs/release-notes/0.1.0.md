# 鼠须管助手 0.1.0（预发布）

第一次公开发布。非鼠须管 / Rime 官方出品。中文系统里显示「鼠须管助手」，其他语言显示 SquirrelHelper。

- 要求：macOS 27 或更新，Apple 芯片。
- 下载 `SquirrelHelper-0.1.0.zip`，解压后把应用拖进「应用程序」。已签名、已公证。
- 功能：
  - 安装鼠须管，并引导添加输入法；
  - 起步方案、接管已有配置、从导出文件导入；
  - 方案、外观、文本替换同步；
  - 一键导出导入；
  - 备份还原；
  - 诊断。

校验：`shasum -a 256 SquirrelHelper-0.1.0.zip`，结果应该是 `7a4e3a6478ef51eab9e3f6206f75d8c7d362e6e69645452bff2a45c11569fc71`（和附件里的 `.sha256` 一样）。

已知限制：
- 没有自己的图标；
- 只支持 Apple 芯片；
- 界面只有中文；
- 应用不在后台常驻，文本替换的变化在打开应用时检查。
