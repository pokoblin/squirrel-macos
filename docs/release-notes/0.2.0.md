# 鼠须管助手 0.2.0

第一个正式版。改用 dmg 发布，加了在线方案清单、试打预览和五笔个人词库编辑器。非鼠须管 / Rime 官方出品。中文系统里显示「鼠须管助手」，其他语言显示 SquirrelHelper。

- 要求：macOS 27 或更新，Apple 芯片。
- 下载 `SquirrelHelper-0.2.0.dmg`，打开后把「鼠须管助手」拖进「应用程序」。应用和 dmg 都已签名、已公证。
- 从 0.1.x 升级：退出旧版，用新版替换「应用程序」里的旧版。设置、个人内容和备份都在，不受影响。

## 新功能

- **试打**（侧边栏新页）：在应用里输入编码，直接看候选、翻页、选词上屏，不用切换输入法。可以看「当前生效」的配置，也可以在点「应用改动」之前先看「应用后的样子」。用的是鼠须管自带的 librime，Lua、OpenCC 照样生效；只在配置的临时副本上运行，不碰 `~/Library/Rime`。这里只看候选内容，字体、颜色这些外观要在真的打字时看。
- **五笔词库**（侧边栏新页，极点五笔用）：
  - 加词时马上显示自动算出的五笔编码，也可以手动改；
  - 列出这个编码现在会出哪些字词，让你选新词排第几；
  - 从文本批量导入（一行一个词，可以带编码和权重，Rime 词库文件也能直接导入），导入前逐行检查；
  - 改编码和位置、删除；
  - 「检查能不能打出来」：用试打功能确认每个词在第几页第几个；
  - 在应用外手改过个人词库时，可以把外面加的词收进来，不会整份覆盖。
- **在线方案清单**：「方案」页有「检查方案清单更新」。清单放在 GitHub 上、签了名，不发新版也能加新方案、修上游结构变化。只在你点按钮时联网；导入别的电脑的导出文件、遇到不认识的方案时也会检查一次。

## 其他改动

- 发布包改成 dmg（打开后把应用拖进「应用程序」就装好了）。
- 应用里新带一个小辅助程序（`Contents/Helpers/rime-preview-helper`），试打和检查词库时用它加载鼠须管的 librime；主程序本身不加载外部的库。

全部条目见仓库里的 `docs/backlog.md`。

校验：`shasum -a 256 SquirrelHelper-0.2.0.dmg`，结果应该是 `e42977f7f024307a9d72203399294f5d2ef0d7507647e0a463e74449f304e017`（和附件里的 `.sha256` 一样）。

已知限制：
- 只支持 Apple 芯片；
- 界面只有中文；
- 词库编辑器这次只做了极点五笔，拼音词库和手动短语的编辑以后再说；
- 应用不在后台常驻，文本替换的变化在打开应用时检查。
