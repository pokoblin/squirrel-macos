# 鼠须管助手 0.3.2

新增：在「诊断」页一键重启鼠须管。非鼠须管 / Rime 官方出品。

- 要求：macOS 27 或更新，Apple 芯片。
- 下载 `SquirrelHelper-0.3.2.dmg`，打开后把「鼠须管助手」拖进「应用程序」。应用和 dmg 都已签名、已公证。
- 从 0.3.1 或更早的版本升级：退出旧版，用新版替换「应用程序」里的旧版。设置、个人内容和备份都在，不受影响。

## 新增

- **重启鼠须管**：输入法被别的软件影响、出问题时，到「诊断」页点「重启鼠须管」。只重启输入法进程，不改配置，也不重新部署；鼠须管卡住时会强制退出再启动。

校验：`shasum -a 256 SquirrelHelper-0.3.2.dmg`，结果应该是 `SHA256_PLACEHOLDER`（和附件里的 `.sha256` 一样）。

已知限制：
- 只支持 Apple 芯片；
- 界面只有中文；
- 词库编辑器只支持极点五笔；候选置顶在雾凇这类自带短语的方案里还不能用；
- 应用不在后台常驻，文本替换的变化在打开应用时检查。
