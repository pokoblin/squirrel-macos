# 鼠须管助手 0.3.1

修复：拼音词库用雾凇大词库时，含 `lüe`、`nüe` 的词用 `lue`、`nue` 打不出来。非鼠须管 / Rime 官方出品。

- 要求：macOS 27 或更新，Apple 芯片。
- 下载 `SquirrelHelper-0.3.1.dmg`，打开后把「鼠须管助手」拖进「应用程序」。应用和 dmg 都已签名、已公证。
- 从 0.3.0 或更早的版本升级：退出旧版，用新版替换「应用程序」里的旧版。设置、个人内容和备份都在，不受影响。

## 修复

- **`lue`、`nue` 打不出词**：雾凇词库把这两个音写成 `lve`、`nve`，所以 `hulue`（忽略）、`celue`（策略）、`nuedai`（虐待）这类编码没有候选，只能打 `hulve`。现在两种写法都能打。这个修复在方案清单里：用雾凇大词库的用户，打开应用后点「应用改动」就会用上（0.3.0 检查更新后也能用上）。
- **接管旧配置时认错拼音词库**：配合上面的修复，接管用雾凇词库的旧配置时，继续认作雾凇词库，不会变成自带词库；缺的规则会在接管时加上并提示。

校验：`shasum -a 256 SquirrelHelper-0.3.1.dmg`，结果应该是 `SHA256_PLACEHOLDER`（和附件里的 `.sha256` 一样）。

已知限制：
- 只支持 Apple 芯片；
- 界面只有中文；
- 词库编辑器只支持极点五笔；候选置顶在雾凇这类自带短语的方案里还不能用；
- 应用不在后台常驻，文本替换的变化在打开应用时检查。
