# 鼠须管助手 0.4.0

新增：五笔拼音混输里，用拼音一个字一个字凑出的词会被记住。非鼠须管 / Rime 官方出品。

- 要求：macOS 27 或更新，Apple 芯片。
- 下载 `SquirrelHelper-0.4.0.dmg`，打开后把「鼠须管助手」拖进「应用程序」。应用和 dmg 都已签名、已公证。
- 从 0.3.2 或更早的版本升级：退出旧版，用新版替换「应用程序」里的旧版。设置、个人内容和备份都在，不受影响。**升级后在鼠须管助手里点一次「应用」**，记词才会打开。

## 新增

- **混输记词**：极点五笔的「拼音混输」「拼音混输繁体」选了雾凇大词库时，拼音打不出的词（比如新出现的人名、菜名）可以一个字一个字选出来，下次直接打全拼就是第一个候选。记错了在候选上按 Ctrl+K 删掉。
  - 五笔的首选不变；拼音单字后面照旧显示五笔编码；繁体混输照旧可以用「`」开头打拼音。
  - 记住的词存在鼠须管自己的用户词库里，导出、导入时一起带上。
  - 拼音词库选「自带词库」时不记词，和以前一样。

校验：`shasum -a 256 SquirrelHelper-0.4.0.dmg`，结果应该是 `（发布时填）`（和附件里的 `.sha256` 一样）。

已知限制：
- 只支持 Apple 芯片；
- 界面只有中文；
- 词库编辑器只支持极点五笔；候选置顶在雾凇这类自带短语的方案里还不能用；
- 应用不在后台常驻，文本替换的变化在打开应用时检查。
