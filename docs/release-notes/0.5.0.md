# 鼠须管助手 0.5.0

新增：可以自己选单按哪个键切换中英文，也可以不用 Shift。非鼠须管 / Rime 官方出品。

- 要求：macOS 27 或更新，Apple 芯片。
- 下载 `SquirrelHelper-0.5.0.dmg`，打开后把「鼠须管助手」拖进「应用程序」。应用和 dmg 都已签名、已公证。
- 从 0.4.0 或更早的版本升级：退出旧版，用新版替换「应用程序」里的旧版。设置、个人内容和备份都在，不受影响。不改新设置就和以前一样。

## 新增

- **「按键」页**：侧边栏「外观」下面多了一页，可以选「单按切换中英文」用哪个键：方案默认、左右 Shift、只用左 Shift、只用右 Shift、左 Control、不用 Shift（只用 Caps Lock）。改完点「应用改动」。
  - 有些应用会抢先截走 Shift+Enter 拿去换行，鼠须管只看到 Shift 按下又松开，就切成了英文。遇到这种情况，选「不用 Shift」或「左 Control」就不会再被误切。
  - Caps Lock 照旧按方案默认切换中英文。
  - 切换时已经打的编码怎么处理，沿用方案原来的做法。
  - 接管已有配置时，手动改过的切换键会认成对应的选项。
  - 命令行：`rimectl settings set switch-key <bothShift|leftShift|rightShift|leftControl|none>`，写 `-` 恢复方案默认。

校验：`shasum -a 256 SquirrelHelper-0.5.0.dmg`，结果应该是 `67a3a2e9b1567ae0825a30ec34878a54d7b9f64f1c079115a4b7ca9782a8a23a`（和附件里的 `.sha256` 一样）。

已知限制：
- 只支持 Apple 芯片；
- 界面只有中文；
- 词库编辑器只支持极点五笔；候选置顶在雾凇这类自带短语的方案里还不能用；
- 应用不在后台常驻，文本替换的变化在打开应用时检查。
