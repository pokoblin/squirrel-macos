# 鼠须管助手 0.2.1

「检查更新」现在也会看你在用的方案有没有新版本，另外修了几处小问题。非鼠须管 / Rime 官方出品。中文系统里显示「鼠须管助手」，其他语言显示 SquirrelHelper。

- 要求：macOS 27 或更新，Apple 芯片。
- 下载 `SquirrelHelper-0.2.1.dmg`，打开后把「鼠须管助手」拖进「应用程序」。应用和 dmg 都已签名、已公证。
- 从 0.2.0 或更早的版本升级：退出旧版，用新版替换「应用程序」里的旧版。设置、个人内容和备份都在，不受影响。

## 新功能

- **检查更新**：「方案」页的「检查方案清单更新」改名为「检查更新」。点一次，除了查方案清单，还会问 GitHub 你在用的每个方案包（雾凇、极点五笔等）现在的最新版本，逐个告诉你「有新版本（上游哪天更新）」还是「已经是最新的」。
  - 只问版本号，不下载方案；和以前一样，只在你点按钮时联网。
  - 有新版本时，底部的「应用改动」可以点。点了和平常一样：先备份，再下载最新的方案、写入、让鼠须管重新部署。不点就什么都不变。
  - 「有更新还没应用」会记下来，退出再打开应用还会提醒。

## 修复

- 诊断页的「下一步」不再让你运行命令行 `rimectl`（发布包里没有它），改成在应用里或系统设置里怎么做。
- 方案清单更新了、还没点「应用改动」就退出应用，下次打开不再忘记提醒。导入时更新了方案清单、导入却失败了，也会提醒应用一次。
- 应用被强制退出后留下的试打临时副本（约 70 MB），下次打开应用时马上清掉。
- 刚发布新的方案清单时，有时会误报「签名不对」：现在检查方案清单时不用本地缓存的旧文件；真的验不过时，提示里会说「刚发布的话过几分钟再试」。
- 方案清单里选项名重复时，不再让主窗口崩溃，而是在读清单时就报错（这类清单不会被采用）。

已知限制：
- 只支持 Apple 芯片；
- 界面只有中文；
- 词库编辑器只支持极点五笔；
- 应用不在后台常驻，文本替换的变化在打开应用时检查。
