# 鼠须管助手 0.3.0

新功能「候选置顶」：词序固定的方案（比如极点五笔）里，某个字老排在后面，现在可以在应用里把它调到第一位。非鼠须管 / Rime 官方出品。中文系统里显示「鼠须管助手」，其他语言显示 SquirrelHelper。

- 要求：macOS 27 或更新，Apple 芯片。
- 下载 `SquirrelHelper-0.3.0.dmg`，打开后把「鼠须管助手」拖进「应用程序」。应用和 dmg 都已签名、已公证。
- 从 0.2.1 或更早的版本升级：退出旧版，用新版替换「应用程序」里的旧版。设置、个人内容和备份都在，不受影响。

## 新功能

- **候选置顶**：「试打」页改名为「试打和置顶」。打出编码后，每个候选旁边有一个图钉，点一下就把它调到这个编码的第一位（比如极点五笔 `kkkk` 下的「口」本来排第 3）。点「应用改动」后生效。
  - 同一页下面有「置顶」列表，列出所有置顶，每条都能「还原」。没装鼠须管、试打出错时，列表照样能用。
  - 一个编码只置顶一个：在同一个编码下再置顶别的，会换掉原来那个。
  - 置顶存成手动短语（应用数据目录里的 `personal/phrases.txt`），导出、导入、备份都会带上。以前导入、接管带进来的手动短语也会列在这里。
  - 有置顶时，应用会给方案加上去重：置顶的字不会在后面再出现一次。本来就有重复候选的编码（比如极点五笔的 `k`、`z`、`zh`、`dh`），重复的那个也会消失，后面的候选往前挪一位。没有置顶时，生成的配置和以前完全一样。
  - 置顶对所有启用的方案都生效。
  - 这几种情况不能置顶，图钉是灰的，鼠标停在上面能看到原因：繁简转换开着的方案（请换到简体方案再置顶）；自带短语的方案（雾凇这类）；只对应前面一段编码的候选（比如拼音打 `nihao` 时的「你」）。
- 底栏会说清楚有哪些没应用的改动；只改了置顶时显示「置顶有改动，还没应用」，「撤销」不会撤销置顶。导入前如果有没应用的置顶，也会提醒会丢掉。

校验：`shasum -a 256 SquirrelHelper-0.3.0.dmg`，结果应该是 `fbcdde3b2848fb8dbc050a1242de2ebc786bb74554221a6080998190ecc617ae`（和附件里的 `.sha256` 一样）。

已知限制：
- 只支持 Apple 芯片；
- 界面只有中文；
- 词库编辑器只支持极点五笔；候选置顶在雾凇这类自带短语的方案里还不能用；
- 应用不在后台常驻，文本替换的变化在打开应用时检查。
