# 第一版实现路线图

- 设计：[2026-10-15-squirrel-macos-v1-design.md](../specs/2026-10-15-squirrel-macos-v1-design.md)
- 日期：2026-10-15

第一版涉及很多相对独立的部分，一份计划写不下，而且后面的细节取决于前面的结果（待验证项、真实的上游目录结构、前一阶段定下来的接口）。所以拆成多个阶段，**每个阶段一份计划，做完一个再写下一个**。每个阶段结束时都有能单独测试的成果。

| 阶段 | 内容 | 成果 | 在哪测 |
|---|---|---|---|
| 0 | 待验证项（设计第 10 节） | 6 项结论写进 `verified-facts.md`；两个测试小工具（打字检查、文本替换读取）；上游目录结构记录 | 测试机 `squirrel-dev` |
| 1 | 工程骨架 + `Catalog` + `PackageStore` | Swift Package（RimeKit + rimectl）；内置 `catalog.json`（3 个包）；`rimectl fetch` 能下载、解压、检查结构、缓存（已完成，2026-10-15） | 宿主机单元测试 + 联网测试 |
| 2 | `Settings` + `ConfigGenerator` | 设置 → 完整 Rime 目录；生成结果能被 `rime_deployer` 编译，打字检查通过；`rimectl generate`（已完成，2026-10-15） | 宿主机（只碰临时目录） |
| 3 | `Deployer` + `Ledger` + 备份还原 | `rimectl apply` / `status` / `restore`：校验、备份、写入、通知鼠须管、检查结果、发现外部改动（已完成，2026-10-15） | 测试机 |
| 4 | `Environment` + `Installer` | `rimectl install`、`rimectl doctor`：检测、下载校验安装鼠须管、检测输入法启用；另有 `rimectl activate`（已完成，2026-10-15） | 干净的临时测试机 |
| 5 | `Takeover` | `rimectl takeover`：认出已有配置（方案、选项、外观、保留的补丁、个人词库、短语），预览会变的文件，确认后接管；文本替换的读取提前到这一阶段（已完成，2026-10-15） | 宿主机 + 测试机 |
| 6 | `Transfer` + `UserDB` | `rimectl export` / `rimectl import`：一键导出（设置、个人内容、输入习惯快照）、新电脑一键导入（已完成，2026-10-15） | 干净的临时测试机 |
| 7 | `TextReplacement` | `rimectl textreplacement status` / `sync` / `off`：数出能用、跳过的条目，看出新增、删掉了几条，同步、关掉；`doctor` 提示没同步的变化（读取在阶段 5 做好；已完成，2026-10-15） | 宿主机（自造数据库）+ 测试机 |
| 8a | 应用骨架 + 第一次打开的引导 | `squirrel-macos.app`（`tools/app/build-app.sh` 打包，临时签名）：装鼠须管、添加输入法、起步方案 / 接管 / 导入（已完成，2026-10-15） | 宿主机单元测试 + 测试机里由用户点一遍 |
| 8b | 主窗口 | 方案、外观、文本替换、导入导出、备份还原、诊断；改了点「应用改动」才生效；出错提示（已完成，2026-10-15） | 宿主机单元测试 + 测试机里由用户检查 |
| 发布 | 0.1.0 | 应用名（鼠须管助手 / SquirrelHelper）、MIT 许可证、Developer ID 签名和公证、GitHub Release（已完成，2026-10-15） | 干净测试机里从下载的 zip 走一遍 |
| 修复 | 0.1.1 | 待改进项清单里应用用户会碰到的 34 条 + 开发工具 6 条；实测和终审又修了 4 条（已完成，2026-10-15） | 宿主机单元测试 + 干净测试机里走一遍 |

发布准备（应用名、导出扩展名、许可证、Developer ID 签名和公证）见设计第 11 节，发布步骤见 [docs/release.md](../../release.md)。

## 阶段之间的约定

- 每个阶段开始前，先读上一阶段的结论，再写本阶段计划；如果结论和设计冲突，先改设计。
- 所有阶段都遵守项目 `CLAUDE.md`：不碰宿主机的 `~/Library/Rime`、`/Library/Input Methods`、输入法启用状态；个人内容只统计条数、比对哈希。
