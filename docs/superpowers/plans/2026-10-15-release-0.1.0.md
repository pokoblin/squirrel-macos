# 发布准备：鼠须管助手 0.1.0 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把第一版做成能公开下载的应用，放在 GitHub Release 上：
- 起正式名称「鼠须管助手」；
- 用 MIT 许可证；
- 用 Developer ID 签名，并通过苹果公证；
- 在干净的测试机里，从「下载的 zip」开始走一遍。

**Architecture:**
- RimeKit 加一个 `AppInfo`，放应用名。界面、生成文件的文件头、导出相关的提示都从这里取名字。
- 内部标识一律不改：bundle ID、数据目录 `~/Library/Application Support/squirrel-macos`、可执行文件名 `SquirrelMacOSApp`、`rimectl`。这样已有的数据和测试机脚本都对得上。
- `tools/app/build-app.sh` 加两个参数（环境变量）：
  - `CONFIGURATION`：release 编译；
  - `SIGN_IDENTITY`：用正式身份签名，同时打开 hardened runtime、加时间戳。
- 新增 `tools/release/build-release.sh`：签名 → 打 zip → 交给苹果公证 → 把公证票据钉到应用上 → 再打 zip → 算 sha256。
- 公证凭据由你自己存进钥匙串，脚本只用凭据的名字。

**Tech Stack:**
- 现有 Swift 6.4 工程；
- `codesign`、`xcrun notarytool`、`xcrun stapler`、`spctl`、`ditto`；
- `gh`（发布 Release）。

**Spec:** [docs/superpowers/specs/2026-10-15-squirrel-macos-v1-design.md](../specs/2026-10-15-squirrel-macos-v1-design.md)，重点是第 11 节（发布前要定的事）、8.3（打包）、第 7 节（文本替换读不了时的处理）。另见 [verified-facts.md](../../verified-facts.md)：第 191 行「正式签名后是否一样，待验证」，以及安装鼠须管用的 `NSAppleScript` 授权。

## Global Constraints

```bash
#!/bin/bash
# 编译应用并拼成 .build/app/鼠须管助手.app，最后一行输出它的路径。
# 默认：debug 编译、本机临时签名，只给测试机用（./tools/vm/install-app.sh）。
# 发布：CONFIGURATION=release SIGN_IDENTITY="Developer ID Application: …" 用正式身份签名
#       （打开 hardened runtime、加时间戳），由 tools/release/build-release.sh 调用。
# 不要在宿主机上运行这个应用：它会读写真实的 ~/Library/Rime。
set -euo pipefail
cd "$(dirname "$0")/../.."
CONFIGURATION="${CONFIGURATION:-debug}"
SIGN_IDENTITY="${SIGN_IDENTITY:--}"
swift build -c "$CONFIGURATION" --product SquirrelMacOSApp >&2
BIN="$(swift build -c "$CONFIGURATION" --show-bin-path)"
APP=".build/app/鼠须管助手.app"
rm -rf .build/app
mkdir -p "$APP/Contents/MacOS" "$APP/Contents/Resources"
cp "$BIN/SquirrelMacOSApp" "$APP/Contents/MacOS/"
# RimeKit 的资源包（方案清单）：Bundle.module 会在 Contents/Resources 里找
cp -R "$BIN/SquirrelMacOS_RimeKit.bundle" "$APP/Contents/Resources/"
cp tools/app/Info.plist "$APP/Contents/Info.plist"
cp LICENSE THIRD-PARTY-NOTICES.md "$APP/Contents/Resources/"
if [ "$SIGN_IDENTITY" = "-" ]; then
  codesign --force --sign - "$APP" >&2
else
  # 里面的资源包先用同一个身份重签（SwiftPM 给它的是临时签名）
  codesign --force --options runtime --timestamp --sign "$SIGN_IDENTITY" "$APP/Contents/Resources/SquirrelMacOS_RimeKit.bundle" >&2
  codesign --force --options runtime --timestamp --sign "$SIGN_IDENTITY" "$APP" >&2
fi
echo "$APP"
```

```bash
#!/bin/bash
# 打发布包：release 编译 → Developer ID 签名（hardened runtime）→ 公证 → 钉上公证票据 → 打 zip、算 sha256。
# 用法：
#   ./tools/release/build-release.sh                    完整流程（先按 docs/release.md 存好公证凭据）
#   SKIP_NOTARIZE=1 ./tools/release/build-release.sh    只签名、不公证（试流程用）
# 环境变量：SIGN_IDENTITY（默认 TONDA K.K. 的 Developer ID）、NOTARY_PROFILE（默认 squirrel-helper-notary）
# 版本号取自 tools/app/Info.plist 的 CFBundleShortVersionString。
set -euo pipefail
cd "$(dirname "$0")/../.."
SIGN_IDENTITY="${SIGN_IDENTITY:-Developer ID Application: TONDA K.K. (VS555M5VA8)}"
NOTARY_PROFILE="${NOTARY_PROFILE:-squirrel-helper-notary}"
VERSION="$(/usr/libexec/PlistBuddy -c 'Print :CFBundleShortVersionString' tools/app/Info.plist)"
OUT=".build/release-out"
ZIP="$OUT/SquirrelHelper-$VERSION.zip"
rm -rf "$OUT"
mkdir -p "$OUT"

APP="$(CONFIGURATION=release SIGN_IDENTITY="$SIGN_IDENTITY" ./tools/app/build-app.sh | tail -1)"
codesign --verify --deep --strict --verbose=2 "$APP" >&2

if [ "${SKIP_NOTARIZE:-}" = "1" ]; then
  echo "注意：没有公证（SKIP_NOTARIZE=1），这个包不能发布" >&2
else
  ditto -c -k --keepParent "$APP" "$OUT/upload.zip"
  result="$(xcrun notarytool submit "$OUT/upload.zip" --keychain-profile "$NOTARY_PROFILE" --wait --output-format json)"
  status="$(printf '%s' "$result" | plutil -extract status raw -o - -)"
  id="$(printf '%s' "$result" | plutil -extract id raw -o - -)"
  echo "公证结果：$status（$id）" >&2
  if [ "$status" != "Accepted" ]; then
    xcrun notarytool log "$id" --keychain-profile "$NOTARY_PROFILE" >&2
    exit 1
  fi
  rm "$OUT/upload.zip"
  xcrun stapler staple "$APP" >&2
  xcrun stapler validate "$APP" >&2
  spctl --assess --type execute --verbose=4 "$APP" >&2
fi

ditto -c -k --keepParent "$APP" "$ZIP"
(cd "$OUT" && shasum -a 256 "$(basename "$ZIP")" > "$(basename "$ZIP").sha256")
echo "$ZIP"
```
