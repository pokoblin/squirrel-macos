## 第一台：发现「装好后误报没有输入源」

装好鼠须管后，点「打开系统设置」，系统设置没有打开。应用显示「出了点问题：系统里没有鼠须管的输入源，重新注册也没用，请重新安装鼠须管」。

查到的原因：
- 应用是在装鼠须管**之前**打开的。同一个进程里，TIS（系统的输入源列表）看不到刚装好的鼠须管。
- 应用就走到了「重新注册」那条路，等不到结果，报了上面那句。这句是误导，其实不用重装。
- 阶段 8a 的测试机以前装过鼠须管，所以当时没复现。

修复：装好后直接显示「请重新打开这个应用」，按钮「重新打开应用」会自己关掉再打开。打开后应用看得到鼠须管，接着往下走。有测试。

## 第二台：重新走一遍

| 步骤 | 用户看到的 | |
|---|---|---|
| 安装时在授权框点「取消」 | 回到「第一步」，上面多一句「你取消了授权…」，不是出错页 | ✅ |

| 打字 | **打出来是英文**：输入法菜单里没有鼠须管，系统设置里有。注销再登录后正常 | ⚠️ → 加了提醒 |
| 方案页改了再改回原样 | 底部「有改动还没应用」消失 | ✅ |
| 清掉应用数据，接管页点「改用起步方案」 | 先弹确认；点取消什么都不变；确认后「设置好了」 | ✅ |

SSH 检查：暂存区是空的；备份 1 份。

打出来是英文的原因：
- 安装包的脚本在日志里写「User already registered / enabled」，但那是 TIS 的旧数据（日志里有 `TISFileInterrogator … old data`），实际没有启用；
- 系统的输入法设置里也没有鼠须管；
- 注销再登录后，菜单里有了，能打中文。

阶段 8a 也见过一次「菜单里没有鼠须管」。这和 [install-test-log.md](install-test-log.md) 里「不用注销」的结论不一致：**刚装好时，有时要注销再登录**。

修复：引导完成时，如果还没切换到鼠须管，完成页提醒「注销再登录一次」。有测试。这一次没法在测试机里复现，所以没实测提醒有没有显示出来。

另外：测试中鼠标左键一度变成右键，原因是虚拟机窗口里 Control 键卡住了。按一下 Control 后恢复。

## 结论

- 引导里取消授权、输错密码的说法，主窗口改回原样，接管页的确认，都走通了。
- 修了两个实测发现的问题：
  - 装好鼠须管后误报「没有输入源」：改成重新打开应用；
  - 有时要注销才认得出鼠须管：完成页加提醒。
- 等部署时显示「已经添加好了。正在启动鼠须管…」、「重新打开系统设置」按钮，这次没走到。重新打开后应用直接往下走了，所以没实测；这两处有单元测试。
